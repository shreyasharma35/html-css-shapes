# HTML & CSS Shapes Practice

A beginner-level HTML and CSS practice project created while learning the fundamentals of web development.

## About the Project

This project displays three basic shapes using HTML and CSS:

* Square
* Circle
* Diamond

Each shape contains a number and has a different background color when hovered over.

## Concepts Practiced

* HTML structure
* CSS selectors
* CSS Flexbox
* `display: flex`
* `align-items`
* `justify-content`
* CSS borders
* `border-radius`
* CSS transformations
* Hover effects
* Basic positioning and spacing

## Technologies Used

* HTML5
* CSS3
